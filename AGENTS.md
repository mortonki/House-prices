# Agents Instructions

## Development Environment
- Use `uv` for package and environment management.
- Run the project using `uv run house-prices`.
- Use `uv run python src/dataloader.py` to download the dataset.

## Project Structure
- Source code is located in the `src/` directory.
- The main package is `house_prices`.
- `dataloader.py` is a standalone script for data acquisition.
